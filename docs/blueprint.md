# **App Name**: Raahi AI

## Core Features:

- AI Route Optimizer: Suggests best route combinations (Train+Cab, Flight+Bus, etc.) based on seat availability, price, time-to-reach, and cancellations, using Shravya AI as a reasoning tool.
- Train Availability Finder: Real-time availability check for trains with filtering options and alternative nearby station options, drawing data from the IRCTC API.
- Flight Deals Aggregator: Aggregates flight deals from APIs like Skyscanner or Cleartrip with filters for non-stop flights and luggage allowance.
- Bus Booking: Integrates Redbus, Abhibus, or official State RTC APIs to allow booking and show boarding points, bus amenities, and timings.
- Cab & Rideshare Integration: Integrates Ola/Uber APIs or uses Way.com for carpooling, to facilitate cab booking.
- Smart Filters Panel: Offers preferred mode, time constraints, and budget limit filters to help focus search results

## Style Guidelines:

- Primary color: Vibrant orange (#FF9933) to convey energy and trustworthiness, reflecting the fast-paced travel environment in India.
- Background color: Light tan (#F5ECCE), subtly desaturated from the primary hue to create a warm, inviting backdrop without overwhelming the user.
- Accent color: Muted gold (#D4A273), an analogous color that suggests sophistication and reliability, used for highlights and calls to action.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, objective, neutral look that will enhance the sense of trustworthiness.
- Use clear, modern icons representing each mode of transport (train, bus, flight, car) to enhance usability and provide a quick visual reference.
- A clean, card-based layout will present travel options clearly and concisely, with important details like price and time highlighted for easy comparison.
- Subtle animations, such as smooth transitions and loading indicators, will enhance the app's responsiveness and create a more engaging user experience.
